## 最常踩的坑：写冲突 1254291

官方原文说明：**同一数据表并发调用读写接口或请求过快会出现冲突**；多维表格底层按版本维度串行处理，**不支持并发**。官方建议：「若操作量较大，建议在接口与接口之间增加 **0.5 或 1 秒**的延迟」。

BasePilot 的处理：`per-table_id` 串行队列 + `0.5s` 节流，不同数据表之间仍可并行。

若客户现场仍冲突，把 `BASEPILOT_WRITE_INTERVAL` 调大到 `1.0`。

## 不重试，按指引处理（25 条）

### `1254003` WrongBaseToken（app_token 错误）

**现场动作**：app_token 不正确。从多维表格 URL 中取：URL 以 feishu.cn/base 开头时，base 后那段即为 app_token；若以 feishu.cn/wiki 开头，需先调 wiki-v2/space/getNode 拿 obj_token。

- 检索关键词：app_token / URL

### `1254004` WrongTableId（table_id 错误）

**现场动作**：table_id 不正确。可从多维表格 URL 直接取，或调用「列出数据表」接口重新获取。

- 检索关键词：table_id / 列出数据表

### `1254012` NotSupportFieldOrView（不支持的字段或视图）

**现场动作**：公式、查找引用、创建时间、修改时间、自动编号、按钮等系统字段**不能通过 API 写入**。请改为写入其数据源字段。

- 检索关键词：公式 / 系统字段

### `1254014` FieldNameDuplicated（字段名重复）

**现场动作**：同一张表内字段名不能重复。请修改字段名或先删除已有字段。

- 检索关键词：重复

### `1254015` FieldTypeValueNotMatch（字段类型不匹配）

**现场动作**：该字段不接受这种类型的值，请先运行 bitable_inspect_schema 确认字段类型。

- 检索关键词：字段类型

### `1254037` Invalid client token（幂等键格式非法）

**现场动作**：client_token 必须是 uuidv4 格式。这通常来自调用方手动传参，请改用默认生成的幂等键。

- 检索关键词：uuidv4

### `1254040` BaseTokenNotFound（多维表格不存在）

**现场动作**：app_token 指向的多维表格不存在或当前应用无权访问。请确认链接是否有效，以及是否已把该多维表格授权给应用。

- 检索关键词：app_token / 授权

### `1254041` TableIdNotFound（数据表不存在）

**现场动作**：table_id 指向的数据表不存在，请调用「列出数据表」接口核对。

- 检索关键词：table_id / 核对

### `1254043` RecordIdNotFound（记录不存在）

**现场动作**：record_id 不存在。请先用 search_records 查询确认记录已被删除或从未存在。

- 检索关键词：record_id / 查询

### `1254045` FieldNameNotFound（字段名不存在）

**现场动作**：字段名必须与多维表格中**完全一致** —— 界面上看到的名字可能含不可见空格或换行。建议先运行 bitable_inspect_schema 拿到准确字段名。

- 检索关键词：完全一致 / 字段名

### `1254062` SingleSelectFieldConvFail（单选字段格式错误）

**现场动作**：单选字段要求传**字符串**，例如 "选项A"，而不是数组 ["选项A"]。这是最常见的错误。

- 检索关键词：字符串 / 数组

### `1254063` MultiSelectFieldConvFail（多选字段格式错误）

**现场动作**：多选字段要求传字符串数组，例如 ["选项A", "选项B"]。

- 检索关键词：数组

### `1254064` DatetimeFieldConvFail（日期字段格式错误）

**现场动作**：日期字段要求传 **13 位毫秒时间戳**（例如 1674206443000），不是秒、也不是日期字符串。

- 检索关键词：毫秒 / 时间戳

### `1254065` CheckboxFieldConvFail（复选框格式错误）

**现场动作**：复选框字段要求传布尔值 true / false。

- 检索关键词：布尔

### `1254066` UserFieldConvFail（人员字段格式错误）

**现场动作**：人员字段要求传数组对象 [{"id": "ou_xxx"}]，且**只支持 id 参数**。传字符串或 name 都会失败。传 null 可清空该字段。

- 检索关键词：id / 数组

### `1254068` URLFieldConvFail（超链接字段格式错误）

**现场动作**：超链接字段要求传 {"link": "...", "text": "..."} 对象。

- 检索关键词：link / text

### `1254069` AttachmentFieldConvFail（附件字段格式错误）

**现场动作**：附件字段不能直接传本地路径或外部 URL。必须先调drive/v1/medias/upload_all 上传拿到 file_token，再传 [{"file_token": "..."}]。

- 检索关键词：file_token / 上传

### `1254074` 关联字段参数无效

**现场动作**：关联字段（SingleLink / DuplexLink）要求传**字符串数组**（record_id 的数组），例如 ["recXXX", "recYYY"]。

- 检索关键词：字符串数组 / record_id

### `1254100` TableExceedLimit（数据表数量超限）

**现场动作**：单表内数据表数量已达上限 100 张，请合并同类台账。

- 检索关键词：上限 / 100

### `1254103` RecordExceedLimit（记录数超限）

**现场动作**：单表记录数已达上限 20000 条，请考虑拆分数据表或归档历史数据。

- 检索关键词：上限 / 20000

### `1254107` FilterLengthExceedLimit（过滤表达式超长）

**现场动作**：filter 表达式超过 2000 字符，请简化过滤条件。

- 检索关键词：2000 / 简化

### `1254108` SortLengthExceedLimit（排序表达式超长）

**现场动作**：sort 表达式超过 1000 字符，请减少排序字段。

- 检索关键词：1000 / 排序

### `1254302` Permission denied（权限不足）

**现场动作**：解决步骤：① 打开目标多维表格页面；② 点右上角「···」；③ 选择「更多」→「添加文档应用」；④ 把你的自建应用加为可管理协作者。

- 检索关键词：添加文档应用 / 权限

### `1254303` AttachPermNotAllow（附件权限不足）

**现场动作**：上传附件的接口要求应用对该多维表格有管理权限。请确认已通过「添加文档应用」完成授权。

- 检索关键词：权限 / 授权

### `1254304` Permission denied（无多维表格访问权限）

**现场动作**：解决步骤：① 打开目标多维表格页面；② 点右上角「···」；③ 选择「更多」→「添加文档应用」；④ 把你的自建应用加为可管理协作者。

## 自动退避重试（4 条）

### `1254290` TooManyRequest（频率超限）

**现场动作**：触发了接口频率限制。BasePilot 已自动退避重试；若持续出现，请降低并发或调大节流间隔。

- 检索关键词：频率 / 退避

### `1254291` Write conflict（写冲突）

**现场动作**：同一数据表并发写或请求过快。官方建议在接口之间增加 0.5-1 秒延迟。BasePilot 已按单表串行 + 节流处理并自动重试；若仍冲突，请把 BASEPILOT_WRITE_INTERVAL 调大到 1.0。

- 检索关键词：写冲突 / 串行 / 延迟

### `1254607` Data not ready（数据未就绪）

**现场动作**：多维表格底层按版本维度串行处理，不支持并发。BasePilot 会退避后重试，请稍候。

- 检索关键词：就绪 / 退避

### `1255040` Request timed out（网关超时）

**现场动作**：请求超时，通常是网络或飞书侧瞬时抖动，已自动重试。

- 检索关键词：超时

## 长退避重试（1 条）

### `1254036` Bitable is copying（多维表格副本复制中）

**现场动作**：多维表格正在复制，复制是异步操作。请等待复制完成后再写入，BasePilot 会按 3s/6s/12s 退避重试，最多 5 次。

- 检索关键词：复制 / 等待

## 重新生成幂等键后重试（2 条）

**现场动作**：相同幂等键重复提交，BasePilot 已更换 client_token 后重试。

- 检索关键词：重复 / 更换

**现场动作**：相同 client_token 在同一 base 版本上重复提交。BasePilot 已重新生成 uuid4 作为幂等键并重试。

- 检索关键词：幂等 / 重新生成

## 现场排查顺序（403 最常见）

遇到「调用成功但没数据」或「权限相关报错」，按此顺序查：

1. **应用有没有发布？** 自建应用改完权限必须由管理员审核发布版本，
   否则 API 返回权限错误（403）。这是最常见的'代码没错但跑不通'。
2. **多维表格授权了吗？** 打开目标表 → 右上角「···」→
   「更多」→「添加文档应用」→ 加入你的自建应用。
3. **权限粒度够吗？** 读写需要 `bitable:app`，只读是 `bitable:app:readonly`。
   按最小权限申请，跑通再加。
4. **开了高级权限？** 开了之后调用可能**成功但返回空**。
   确认调用身份有可管理权限。
5. **表在复制中？** 错误码 `1254036`，异步操作，等待完成。

跑 `bitable_doctor` 可以一次性拿到以上全部检查结果。
